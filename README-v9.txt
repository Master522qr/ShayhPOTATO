LunaVisual Site v9

1. Загружайте СОДЕРЖИМОЕ архива в корень GitHub Pages. index.html должен лежать в корне репозитория.
2. Лаунчера внутри архива НЕТ. Его HTTPS-ссылка задаётся в Настройки сайта -> Ссылка установки лаунчера.
3. База Supabase LunaVisual уже обновлена до v9 в проекте pdibtleothnnmihhrbcr.
4. Для нового/резервного проекта: сначала supabase_setup.sql, затем supabase_upgrade_v9.sql.
5. Ввод ключей сейчас выключен по умолчанию. Admin -> Настройки сайта -> Система обычных ключей включает запуск. Пока выключено, ключ НЕ помечается использованным и срок НЕ начинается.
6. После активации used_at является временем старта. activation_expires_at фиксирует конец срока. Неиспользованный ключ бессрочно ждёт активации.
7. Admin/Super Admin: роли, ключи, Alpha, новости, заявки креаторов, модельки, выдача моделек, подписки и завершение сессий.
8. Креатор-проверка Edge Functions задеплоена. Для реального OAuth всё равно нужны CLIENT_ID/CLIENT_SECRET приложений Google, TikTok и Twitch в Supabase Secrets.
9. Модельки Luna Horns / Moon Mask / Luna Wings добавлены как стартовый каталог с превью. Реальные 3D/model-файлы не копировались с чужих сайтов: загрузите разрешённые вами файлы через админку. После выдачи asset_path приходит клиенту через get_lunavisual_launcher_state().
10. Новый лаунчер должен использовать LAUNCHER-INTEGRATION-v9.txt.
