LunaVisual v6 — установка сайта, базы и Creator Program
=====================================

1) БАЗА SUPABASE
----------------
Проект: https://pdibtleothnnmihhrbcr.supabase.co

Откройте Supabase Dashboard -> SQL Editor и выполните файл:
  supabase_setup.sql

После регистрации аккаунта владельца один раз выполните в SQL Editor:
  select public.bootstrap_lunavisual_owner('EMAIL_ВЛАДЕЛЬЦА');

После этого владелец станет super_admin. ID/email владельца НЕ зашиты в HTML/JS.
Администраторы и super_admin хранятся только в public.admin_roles.

2) GITHUB PAGES + ДОМЕН
-----------------------
В корне уже лежит CNAME со значением:
  lunavisual.ru

В GitHub: Repository -> Settings -> Pages -> Custom domain:
  lunavisual.ru

После правильной настройки DNS включите Enforce HTTPS.
site-config.js дополнительно переводит http:// на https:// в браузере.
Основной URL сайта:
  https://lunavisual.ru

3) НОВОСТИ
----------
В admin.html есть форма публикации новости: заголовок + описание + фото.
Фото автоматически загружается в Supabase Storage bucket "news".
Опубликованные записи появляются на news.html.

4) РАНГИ
--------
Профильный ранг хранится в profiles.rank:
  user
  admin
  youtube
  tiktok
  twitch_streamer
  tester

Админ-права (admin / super_admin) хранятся отдельно в admin_roles.
Обычный admin может выдавать профильные ранги.
Только super_admin может выдавать/снимать административные права.

5) ПРОГРАММА БЛОГЕРОВ
---------------------
Страница: creators.html
Порог подачи заявки:
  YouTube: 1000 подписчиков
  TikTok: 2000 подписчиков
  Twitch: 500 фолловеров

Подключённые Platform ID, ник, аватар и доступная статистика записываются в creator_connections.
Заявки — creator_applications.

OAuth настроен через Supabase Edge Functions, но для реального подключения платформ
вам нужно создать приложения у Google, TikTok и Twitch и добавить Client ID / Secret.
Подробности: OAUTH-CREATORS-SETUP.txt

Важно: сайт запрашивает минимальные READ-ONLY разрешения, необходимые для подтверждения
аккаунта и статистики. Полный доступ к публикации/удалению контента не нужен.

6) КЛЮЧИ
--------
Обычные ключи:
  LUNAVISUALKEY-0000-0000-0000-0000-0000

Alpha-ключи:
  ALPHALUNA-KEY-XXXXXX-XXXXXX-XXXXXX-XXXXXX-XXXXXX-XXXXXX-XXXXXX

В админке можно создать до 10000 ключей (клиент разбивает запрос на партии по 500),
указать любое число дней или "Навсегда".

Если пользователь активирует обычный ключ "Навсегда", он автоматически получает
Alpha-доступ на 7 дней бесплатно.

Alpha-доступ имеет отдельную систему ключей и отображается в профиле/launcher state.

7) МОДЕЛЬКИ
-----------
Страница models.html открывается только после входа.
Каталог хранится в models, покупки-заявки в model_orders, выданные права в user_models.

Администратор может:
  - добавить модельку;
  - загрузить превью;
  - загрузить закрытый файл модели;
  - выдать модель пользователю по заказу.

Launcher API:
  RPC get_lunavisual_launcher_state() возвращает список выданных моделей;
  RPC get_my_lunavisual_models() возвращает каталог выданных пользователю моделей;
  Edge Function model-download-url выдаёт временную signed URL только владельцу модели.

В комплект сайта добавлен полный LunaVisual-Launcher.zip. Его интерфейс уже видит ранг, Alpha и новые новости из базы.
Серверная часть прав на модели и закрытых загрузок подготовлена; для физической установки произвольного файла модели внутрь мода нужен поддерживаемый самим модом формат/каталог модели.

8) CAPTCHA
----------
CAPTCHA из регистрации удалена по запросу. Supabase Auth продолжает сохранять сессию
пользователя в браузере через persistSession.

9) СЕКРЕТЫ
----------
НИКОГДА не вставляйте sb_secret_*, service_role, Google/TikTok/Twitch client secrets
в HTML, JS или публичный GitHub-репозиторий.

Edge Functions получают серверный Supabase secret key из защищённого окружения Supabase автоматически; он не хранится в файлах сайта.
OAuth secrets задаются через Supabase Secrets. См. OAUTH-CREATORS-SETUP.txt.

Если секретный ключ Supabase ранее публиковался или отправлялся в небезопасное место,
после настройки рекомендуется отозвать/перевыпустить его.
